# Swiggy Orders Data Analysis

## Project Overview

This project analyzes Swiggy order data to understand sales performance, customer ordering patterns, restaurant performance, and other business insights.

The analysis was performed using **Microsoft Excel**, including data cleaning, formulas, Pivot Tables, charts, and dashboard-style analysis.

## Objectives

* Analyze overall order and sales performance
* Identify top-performing restaurants and food categories
* Understand customer ordering patterns
* Analyze revenue and order trends
* Identify useful business insights from the order data
* Present findings using Excel-based visualizations

## Tools & Technologies

* Microsoft Excel
* Pivot Tables
* Excel Charts
* Excel Formulas
* Data Cleaning
* Data Analysis
* Dashboard & Data Visualization

## Dataset

The dataset contains Swiggy order-related information used to analyze orders, customers, restaurants, food items, quantities, prices, and revenue-related metrics.

## Key Analysis

The project includes analysis of:

* Total Orders
* Total Revenue
* Average Order Value
* Restaurant Performance
* Food Category Performance
* Customer Ordering Trends
* Order and Revenue Trends
* Top Restaurants / Food Items
* Other relevant business KPIs
